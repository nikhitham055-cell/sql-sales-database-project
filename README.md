# SQL Sales Database Project

A MySQL-based sales database project created to practice SQL queries and basic data analysis.

## Topics Covered

* Basic SELECT queries
* WHERE conditions
* ORDER BY
* LIMIT
* Aggregate functions
* GROUP BY
* HAVING
* INNER JOIN
* Multiple table JOINs
* CASE statements
* Subqueries
* UPDATE
* ALTER TABLE
* DELETE
* Basic data analysis queries

## SQL Concepts Practiced

The project contains 35 SQL exercises covering:

1. Basic Queries
2. Aggregate Functions
3. GROUP BY
4. JOINs
5. CASE Statements
6. Subqueries
7. UPDATE / ALTER / DELETE
8. Data Analyst-oriented SQL questions

## Database

Database name:

`sales`

Main tables:

* `customers`
* `products`
* `orders`
* `order_details`

## Tools Used

* MySQL
* MySQL Workbench

## How to Run

1. Open MySQL Workbench.
2. Open `sales_database.sql`.
3. Make sure the `sales` database and required tables are available.
4. Execute the queries individually or as required.
